## 使用入口

- `TOKEN消耗自动播报/README.md`：查看 token 消耗日报的配置、dry-run 和发送方式。
- `周报自动化提醒/README.md`：查看周报提醒自动化的时间表、配置和飞书写回方式。
- `SKILL.md`：查看班级申请审批技能说明。该资产仍需补齐或关联实际脚本 `approve-class-emails.ps1`。
- `compensation-workbook-skill-upload.zip`：保留为技能上传包。使用前需确认来源、生成方式和敏感信息检查结果。

## 公开仓库安全边界

不得提交以下内容：

- token、密码、授权码、cookie、私钥。
- 真实 `.env`、本地配置、浏览器会话、运行日志。
- 内部钉钉群 ID、机器人 webhook、飞书文档链接、内部系统链接。
- 真实成员名单、联系方式、会议记录原文、内部待办详情。
- 业务导出数据、截图、报表结果或任何无法公开的数据文件。

真实配置应使用 `.env.example`、`*.example.json` 等示例文件表达字段结构，并将实际值保存在本地、私有仓库或受控部署环境中。

## 维护规则

- 新增工具时，需要同步补充根目录资产清单和 `ASSET_GOVERNANCE.md`。
- 每个可运行资产都应包含 README、示例配置、运行方式、验证方式和安全说明。
- 状态为 `partial_governed` 的资产需要写明缺口和下一步动作。
- 废弃或无法说明用途的资产应标记为归档，或从公开仓库移除。
